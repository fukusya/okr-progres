K-1Menjalankan aplikasi di laptop dengan Docker14 Okt 2026 · cukup satu perintah, tanpa memasang Node atau menyalin pengaturan rahasiaDigabung

Manfaat: siapa pun yang membantu (developer, QA) bisa menjalankan aplikasi OKR di laptopnya sendiri dalam beberapa menit.

  • Memakai database lokal sendiri berisi data contoh fiktif (akun @demo.example.test). Database pengembangan bersama dan database production tidak tersentuh sama sekali, jadi pengujian tidak mengganggu data uji pemilik proyek.
  • Data contoh diisi otomatis saat pertama kali dijalankan; bisa dikosongkan dan diisi ulang kapan saja.
  • Hanya untuk laptop. Tidak dipakai hosting/Vercel dan tidak mengubah cara kerja aplikasi.

Cara menjalankan: pasang Docker Desktop, buka folder aplikasi, jalankan docker compose up -d, lalu buka http://localhost:4000. Panduan lengkap ada di docker/README.md di repo aplikasi.

Status: digabung ke branch redesign/dashboard-divisi lewat pull request #2 (14 Okt). Dicoba langsung: aplikasi terbuka, ganti peran Lead/Anggota/Admin/C-level berjalan.
